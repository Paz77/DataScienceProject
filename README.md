# DBLP Research DNA — CS Topic Drift Analysis

Analyzing the DBLP V10 dataset (AMiner) to track how CS research areas emerge, converge, and drift over time. We build TF-IDF "Research DNA" fingerprints for 6 venues and visualize how they relate and shift.

**Venues:** ICML, KDD, SIGMOD, CVPR, ACL, VLDB

**Team:** Elvin, Carlos, Kelvin Sanchez (2355005)

---

## Notebook

All analysis lives in a single notebook: `research_dna_analysis.ipynb`

| Section | Owner | Task | Depends on |
|---|---|---|---|
| 1 — Preprocessing | Elvin | Load & merge DBLP data, build TF-IDF matrix, PCA | nothing |
| 2 — EDA | Elvin | Distributions, keyword heatmaps, PCA scatterplot | Section 1 outputs |
| 3 — Co-Author Network | Elvin | Co-author graph, bridge authors, venue communities | Section 1 outputs |
| 4–6 — Clustering & Anomaly Detection | Carlos | Venue clustering, anomaly detection, cross-venue profiling | Section 1 outputs |
| 7–9 — Classification & Temporal Dynamics | Kelvin | Classification, temporal classification | Section 1 outputs |

**Run Section 1 first.** Its outputs land in `data/processed/` and everything else reads from there.

## Setup

**1. Clone the repo**
```bash
git clone <repo-url>
cd DataScienceProject
```

**2. Create a virtual environment and install dependencies**
```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

**3. Get the data**

Download the 4 DBLP JSON files (`dblp-ref-0.json` through `dblp-ref-3.json`) and put them in `data/`

**4. Open `research_dna_analysis.ipynb` in Jupyter or VS Code**

---

## Data

Raw data is from the [DBLP-Citation-network V10](https://www.aminer.org/citation) dataset (~3.2M papers). We sample up to 3,000 papers per venue (~18k total) and filter to the 6 venues above.
